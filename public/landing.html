El sistema de gestión para tu negocio

Caja rápida

Ventas en segundos

Interfaz de caja intuitiva pensada para agilidad: productos por código de barras, QR o búsqueda instantánea. Ventas a granel, descuentos y múltiples métodos de pago.

  • Caja rápida con teclado o lector
  • Códigos de barras y QR generados automáticamente
  • Pago en efectivo, tarjeta, transferencia o mixto
  • Display para cliente en tiempo real
Control total

Inventario que se actualiza solo

Cada venta descuenta stock automáticamente. Categorías, alertas de reabastecimiento, ajustes y movimientos con historial completo.

  • Stock en tiempo real por producto
  • Alertas de mínimo y reabastecimiento
  • Importación de productos desde CSV/Excel
  • Historial de movimientos (entradas, salidas, ajustes)
Multi-empresa

Varias empresas, un solo sistema

Cada cuenta es una empresa independiente, con sus tiendas, usuarios y datos aislados. Crea tu empresa, agrega sucursales y asigna tu equipo con roles específicos.

  • Múltiples tiendas por empresa
  • Usuarios con roles: Admin, Gerente, Cajero
  • Datos 100% aislados entre empresas
  • Terminales y cajas por sucursal
Dinero bajo control

Cajas registradoras con arqueo

Abre y cierra cajas, registra movimientos de entrada y salida, y detecta diferencias al instante.

  • Apertura y cierre de caja por usuario
  • Movimientos: entradas, retiros, ventas
  • Arqueo con diferencia calculada
  • Cancelación de ventas con devolución de stock
Crece con datos

Promociones y reportes que venden

Crea descuentos, paquetes y ofertas por cantidad. Consulta reportes y gráficas para tomar decisiones informadas.

  • Promociones: descuento simple, por cantidad, paquete o cuenta
  • Reportes diarios de ventas y ganancias
  • Productos más vendidos y categorías top
  • Dashboard con estadísticas en tiempo real
Tus datos, tu servidor

Self-hosted y open source

Instálalo con Docker en tu propio servidor en minutos. Sin suscripciones, sin límites, sin que nadie más toque tus datos.

  • Docker: docker compose up -d
  • Todas las funciones desbloqueadas
  • API REST documentada para agentes e integraciones
  • Código en GitHub bajo licencia Apache 2.0
